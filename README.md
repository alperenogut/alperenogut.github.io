# İsmail Alperen Öğüt — academic homepage

A minimal static personal website designed for GitHub Pages.

## Files

- `index.html` — complete website, including the CSS

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

For the simplest URL, name the repository:

`YOURUSERNAME.github.io`

Then the site will be served at:

`https://YOURUSERNAME.github.io/`

## Custom domain

If you later add your own domain, configure it under:

**Settings → Pages → Custom domain**

The site requires no framework, package manager, build step, JavaScript, database, or external stylesheet.
